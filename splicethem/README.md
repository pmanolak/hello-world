Splice Them
===========

Python script to build a mix CD from wave files, with proper
fade-out overlapping, without the duplicative overhead of importing
everything into an Audacity project.  Input is a JSON object
referring to RIFF WAVE files in stereo 44100 Hz 16-bit linear PCM.
Documentation in the docstring.

Originally developed in 2016, rediscovered in 2026 while editing
"The Making of Family Size VM", and published as part of
Damian Yerrick's software archaeology effort.
